## Current Project Summary

Corolla Fix Helper is a private, local-first repair helper for a 2009 Toyota Corolla LE 1.8L.

The current app is more than the original Day 1 PDF organizer idea. It now has a working V1 baseline with:

- Dashboard
- Documents
- Search
- Symptoms
- Procedures
- Notes
- Settings
- local SQLite storage
- local PDF upload storage
- manual Settings backup export
- production serving of the built React client from Express
- a Google Compute Engine VM demo path documented in the repo

## Current V1 Status

V1 is documented as ready to tag from a Node.js `>=24 <25` validation run.

The latest documented validation used:

- Node.js `v24.15.0`
- npm `11.4.2`

The documented green commands are:

```bash
npm run install:all
npm run build
npm run test
npm run test:server
npm run test:client
```

Do not validate or tag V1 from Node 20. The backend uses `node:sqlite` with `DatabaseSync`, so Node.js `>=24 <25` is the expected runtime range for this repo.

## Current Product Rules

1. Keep V1 single-vehicle and local-first.
2. Use sample or fake PDFs for public demos until authentication exists.
3. Do not present the app as having cloud sync, user accounts, AI chat, embeddings, RAG, OCR for every file, or multi-vehicle support.
4. Keep the current V1 deployment path close to the app design: one Node server, one SQLite database file, and one local uploads folder.
5. Cloud Run is not the preferred V1 target unless storage is redesigned away from local files.

## Success Statement

V1 is successful if it helps find and reuse Corolla repair information faster than digging through folders manually, while staying honest about its current local-only limits.

## Best Next Work After V1

Good next candidates are:

1. Deployment hardening for the VM demo path.
2. A tested backup/restore drill before trusting real data.
3. Basic access protection before sharing a public URL.
4. A minimal E2E smoke test for the production build.
5. Later, optional selected-document AI summaries only after the local-first V1 baseline stays stable.
